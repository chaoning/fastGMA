Describe your data and the analysis you want. This page writes a prompt that contains the complete fastGMA documentation and the option list of every module. Give it to an AI assistant, and it suggests which module to use and the commands to run.

用自然语言描述你的数据和想做的分析。本页会生成一段提示词，其中包含 fastGMA 的完整文档和每个模块的全部选项；把它交给 AI 助手，就能得到推荐的模块和可运行的命令。

Examples: 示例：
Open in Claude在 Claude 中打开 Open in ChatGPT在 ChatGPT 中打开

Copy prompt copies the prompt with the full documentation included (about 45k tokens). Paste it into any assistant, such as Claude, ChatGPT, DeepSeek or Kimi. This is the most reliable way.

复制提示词会复制包含完整文档的提示词（约 4.5 万 token），可粘贴到任意 AI 助手，如 Claude、ChatGPT、DeepSeek、Kimi。这是最可靠的方式。

Open in Claude / ChatGPT opens a new chat with a shorter prompt that links to the documentation file. This works when the assistant can read web pages. If it says it cannot open the link, use Copy prompt instead.

在 Claude / ChatGPT 中打开会新建对话，并填入一段较短的提示词，其中给出文档文件的链接。这需要助手能读取网页；如果它表示无法打开链接，请改用复制提示词。

AI suggestions can be wrong. Before running a large job, check each option with fastgma -h <n> and the module page. AI 的建议可能出错。运行大规模任务前，请用 fastgma -h <n> 和对应模块的文档核对每个选项。

The documentation file used by the prompt: llms-full.txt. Nothing you type is sent anywhere by this page.

提示词所用的文档文件：llms-full.txt。本页不会把你输入的内容发送到任何地方。
