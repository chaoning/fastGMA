==> fastgma -h 1 <==

Compute dense genomic relationship matrices (GRMs) in GCTA format:
lower-triangular
float32 `<out>.grm.bin`, "FID IID" `<out>.grm.id`, per-pair SNP counts
`<out>.grm.N.bin`, plus a text `<out>.grm.N` (SNPs used, scale factor).

Defaults:
--grm-type add
--code-type 2
--maf 0.01
--missing-rate 0.05
--val 0

Quick start:
Additive GRM from PLINK BED
fastgma --make-grm --bfile test --out test

Additive GRM from feature matrix
fastgma --make-grm --ffile test --out test

Dominance GRM (statistical coding)
fastgma --make-grm --grm-type dom --bfile test --out test

Variance-scaled alternative
fastgma --make-grm --bfile test --code-type 1 --out test

Additive GRM with SNP-effect variance proportional to (2pq)^alpha
fastgma --make-grm --bfile test --alpha -0.25 --out test

Leave-one-chromosome-out GRM for chromosome 6, with frequencies saved
fastgma --make-grm --bfile test --not-chr 6 --write-freq --out test_loco6

fastgma [OPTIONS]

OPTIONS:
  -h,     --help              Print this help message and exit
  -m,     --make-grm          Calculate GRM
          --threads INT       Number of threads (default: 10)
          --grm-type TEXT:{add,dom} [add]
                              GRM type (add, dom)
          --bfile TEXT Excludes: --ffile
                              Prefix for PLINK binary PED files
          --ffile TEXT Excludes: --bfile
                              Prefix for feature-by-sample matrix files
          --out TEXT REQUIRED Prefix for output file
          --code-type INT:{1,2} [2]  Excludes: --alpha
                              Genotype coding type (1 or 2)
          --alpha FLOAT Excludes: --code-type
                              Additive GRM: SNP-effect variance proportional to (2pq)^alpha
                              (default: -1)
          --npart INT:POSITIVE [[1,1]]  x 2
                              Partition GRM elements: <npart> <ipart>
          --npart-snp INT:POSITIVE [20]
                              Partition SNPs into n parts
          --maf FLOAT [0.01]  MAF cutoff value
          --missing-rate FLOAT [0.05]
                              Maximum allowed missing rate
          --keep TEXT         Keep only these individuals (one IID, or FID IID, per line)
          --remove TEXT       Remove these individuals (one IID, or FID IID, per line)
          --extract TEXT      Use only the SNPs listed in the first column (--bfile)
          --exclude TEXT      Leave out the SNPs listed in the first column (--bfile)
          --chr TEXT ...      Use only these chromosomes, e.g. 1-22 or 1,3,5 (--bfile)
          --not-chr TEXT ...  Leave out these chromosomes, e.g. 6 for a LOCO GRM (--bfile)
          --read-freq TEXT    Use the A1 frequencies in this file (header with SNP, A1, FREQ;
                              --bfile)
          --write-freq        Write the A1 frequency of every selected SNP to <out>.freq
                              (--bfile)
          --val FLOAT [0]     Value added to the GRM diagonal (default: 0)
          --missing-geno TEXT [[NA,Na,na,NAN,NaN,nan,-NAN,-NaN,-nan,<NA>,<na>,N/A,n/a]]  ...
                              Missing genotype values (space-separated)

==> fastgma -h 2 <==
Quick start:
Merge partitioned GRMs
fastgma --process-grm --merge --grm test --npart 5

PCA
fastgma --process-grm --pca --grm test --out test # test.eigenval, test.eigenvec
(top 20 PCs)
fastgma --process-grm --pca --num-pc 0 --grm test --out test # all PCs

Epistatic GRM from two dense GRMs
fastgma --process-grm --make-epis --prefix1 test1 --prefix2 test2 --out test

Reformat GRM
fastgma --process-grm --reformat --grm test --out-fmt 0 --out test #
test.grm.matrix
fastgma --process-grm --reformat --grm test --out-fmt 1 --out test #
test.grm.index_triplet
fastgma --process-grm --reformat --grm test --out-fmt 2 --out test #
test.grm.iid_triplet
fastgma --process-grm --reformat --grm test --out-fmt 3 --out test #
test.grm.bin
fastgma --process-grm --reformat --sparse --grm test --out-fmt 0 --out test #
test.grm.matrix
fastgma --process-grm --reformat --sparse --grm test --out-fmt 1 --out test #
test.grm.index_triplet
fastgma --process-grm --reformat --sparse --grm test --out-fmt 2 --out test #
test.grm.iid_triplet
fastgma --process-grm --reformat --sparse --grm test --out-fmt 3 --out test #
test.grm.sp.bin

GRM inverse
fastgma --process-grm --make-inv --grm test --out-fmt 0 --out test.inv #
test.inv.grm.matrix (diag + --val, default 0.001)
fastgma --process-grm --make-inv --grm test --out-fmt 1 --out test.inv #
test.inv.grm.index_triplet
fastgma --process-grm --make-inv --grm test --out-fmt 2 --out test.inv #
test.inv.grm.iid_triplet
fastgma --process-grm --make-inv --grm test --out-fmt 3 --out test.inv #
test.inv.grm.bin

Output one IID from each close pair
fastgma --process-grm --out-close --grm test --out test

Group related IIDs
fastgma --process-grm --group --grm test --cut-value 0.05

fastgma [OPTIONS]

OPTIONS:
  -h,     --help              Print this help message and exit
  -d,     --process-grm REQUIRED
                              Process an existing GRM
          --threads INT       Number of threads (default: 10)
          --merge             Merge GRM files
          --pca               Perform PCA
          --make-epis         Calculate epistatic GRM
          --reformat          Reformat GRM
          --make-inv          Calculate the inverse of GRM
          --out-close         Drop individuals until no pair exceeds --cut-value; writes
                              <out>.grm.pruned_iid
          --group             Group individuals by GRM relationships
          --grm TEXT          GRM prefix without the .grm suffix
          --out TEXT          Output prefix without the .grm suffix
          --prefix1 TEXT      First dense GRM prefix without the .grm suffix for --make-epis
          --prefix2 TEXT      Second dense GRM prefix without the .grm suffix for --make-epis
          --npart INT         Partition count (for merging)
          --out-fmt INT [2]   Output format: 0=matrix, 1=index_triplet, 2=iid_triplet, 3=binary
          --cut-value FLOAT [0.05]
                              Relatedness threshold for --out-close and --group
          --val FLOAT         Value added to the diagonal before --make-inv (default: 0.001)
          --num-pc INT        Number of leading PCs written by --pca (0 = all; default: 20)
          --sparse [0]        Indicate sparse GRM

          --covar TEXT ...    Numeric covariate column names (supports a:b ranges)
          --class TEXT ...    Categorical covariate column names (one-hot)
          --env-int TEXT ... REQUIRED
                              Interacting environment column names
          --threads INT [10]  Number of threads
          --maxiter0 INT [20]
                              Maximum REML iterations
          --num-rand-vec INT [32]
                              Stochastic trace probe vectors (implicit path)
          --seed UINT [42]    Random seed for MoM / trace probe vectors
          --cc-par0 FLOAT [0.0001]
                              Relative parameter-change convergence threshold
          --cc-gra0 FLOAT [0.01]
                              Gradient-norm convergence threshold
          --cc-logl0 FLOAT [0.01]
                              |Delta(-2logL)| convergence threshold (OR-ed with
                              --cc-par0/--cc-gra0)
          --logl-lanczos INT [15]
                              Lanczos steps for the SLQ log|V| / -2logL estimate (implicit
                              path; 0 = off)
          --pcg-tol FLOAT [1e-05]
                              PCG relative residual tolerance
          --pcg-maxiter INT [500]
                              Maximum PCG iterations
          --precond-rank INT [0]
                              Randomized low-rank preconditioner rank (0 = diagonal only)
          --precond-oversample INT [10]
                              Oversampling columns for the low-rank range finder
          --no-pcg-warmstart  Disable warm-starting each REML iteration's PCG from the previous
                              solution
          --exact-threshold INT [8000]
                              Materialize K and run exact REML when n <= this
          --matvec-block INT [0]
                              RHS columns per streaming GRM pass (0 = auto: one pass per PCG
                              round; caps implicit-path memory)
          --force-implicit    Always use the implicit (streaming) path
          --dry-run           Load data, cache kernel diagonals, time one streaming matvec,
                              then exit
          --in-memory         Load the whole GRM into RAM once (avoids re-streaming it per
                              matvec)
          --grm-single        With --in-memory, store the GRM as float (halves RAM, ample for
                              REML)
          --residualize       fastGxE-compatible: residualize the trait on the fixed effects
                              and environments, then fit with P = V^-1 (default: strict REML
                              keeping the fixed effects in P)
          --no-noisebye       Drop the noise-by-environment component (3-component model)
          --log-trait         Log-transform the trait before residualization (requires positive
                              values)
          --int-trait         Rank-based inverse-normal transform the residualized trait (Blom)
          --no-standardize-env
                              Do not standardize the environment columns
          --missing-data TEXT ...
                              Override missing-value labels
