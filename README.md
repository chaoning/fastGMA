# fastGMA: Fast genomic mixed-model analysis for genome-wide association studies and genomic prediction of complex traits

`fastGMA` is a C++ toolkit for genomic mixed-model analysis of complex traits. It provides efficient methods for:

- genome-wide association studies (GWAS),
- variance component and heritability estimation, and
- genomic prediction.

## Documentation

The user guide, with one page per module, is at <https://chaoning.github.io/fastGMA>.
